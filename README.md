# Leon LiuZX的个人网站

这是一个以"外星人探索地球"为主题的个人网站。通过一个外星观察员的视角，以独特而富有趣味的方式展现个人经历、思考和生活点滴。

## 🚀 主要特点

- **科幻主题**：采用外星人探索地球的独特视角
- **沉浸式体验**：大量动画和交互效果
- **响应式设计**：完美适配从手机到桌面的各种设备
- **主题风格**：低饱和度深色调搭配霓虹光效，营造科幻氛围

## 🛸 页面构成

### 1. 首页 (HomePage)
- 动态的飞船降落动画
- 打字机效果的欢迎信息
- 星空背景效果

### 2. 档案室 (AboutPage)
- 外星档案展示
- 互动式标本墙
- 个人信息卡片

### 3. 探索日志 (ExperiencePage)
- 时间线式经历展示
- 图片画廊
- 详细成就记录

### 4. 星际观察 (ThoughtsPage)
- 终端风格的文章列表
- 动态加载效果
- 标签分类系统

### 5. 外星朋友圈 (LifePage)
- 社交媒体风格界面
- 实时状态更新
- 互动反馈系统

### 6. 星际联络 (ContactPage)
- 多渠道联系方式
- 加密通信效果
- 隐藏彩蛋

## 🛠️ 技术栈

- **核心框架**: Vue 3
- **路由管理**: Vue Router
- **样式处理**: SCSS
- **动画效果**: GSAP
- **字体图标**: Font Awesome
- **代码规范**: ESLint
- **构建工具**: Vite

## 📦 安装与运行

```bash
# 克隆项目
git clone 

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 🎨 主题定制

网站使用CSS变量进行主题配置：

```css
:root {
  --primary-color: #2a3b4c;
  --accent-color: #7e57c2;
  --text-color: #e0e0e0;
  --background-color: #0a0f16;
  --neon-glow: 0 0 10px rgba(126, 87, 194, 0.5);
}
```
